# 拾光咖啡 · 演示单页网站

社区精品咖啡（**虚构演示品牌**）的单文件响应式落地页。

- 单文件 `index.html`，内联 CSS/JS，无构建步骤、无外部依赖
- 浅色 / 深色主题切换（localStorage 记忆）
- 响应式布局 + 滚动入场动画
- 营业时间自动高亮当天
- 地址 / 电话 / 公众号一键复制，附高德地图链接

## 本地预览

直接双击 `index.html`，或用任意静态服务器：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000

## 部署

可托管到 GitHub Pages / Vercel / Netlify 等任意静态托管平台。
首页即 `index.html`。

> ⚠️ 本页为虚构演示，所有品牌、地址、电话、公众号、价格均为模拟数据，仅用于网页设计展示。
